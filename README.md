## Requirements

## Setup
1. Create a virtual environment (powershell):
    ```
    python -m venv .venv
    ```
2. Activate it:
    ```
    .venv\Scripts\Activate.ps1
    ```
3. Dependency installation:
    ```
    pip install -r requirements.txt
    ```
